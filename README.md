# Image-recognition-methods-practices
Методы распознавания образов: лабораторные работы (3 семестр)

# Лабораторные работы

## Лабораторная работа 1: «Алгоритм Виолы-Джонса для детекции объектов на изображениях»

**Задачи:**
1. Загрузка каскадного классификатора и исходного изображения;
2. Обработка изображения;
3. Применение алгоритма Виолы-Джонса для детекции объектов на изображении.

## Лабораторная работа 2: «Поиск ключевых точек на изображении»

**Задачи:**
1. Загрузка каскадного классификатора и исходного изображения;
2. Обработка изображения;
3. Применение алгоритма SIFT для поиска ключевых точек и дескрипторов.

## Лабораторная работа 3: «Классификация объектов на изображении с помощью предобученной нейросети VGG16»

**Задачи:**
1. Импортировать предобученную нейросеть VGG16;
2. Использовать нейросеть VGG16 для классификации объектов на изображении;
3. Реализовать наложение шума на изображение;
4. Проанализировать как нейронная сеть будет классифицировать зашумленное изображение и на каком этапе начнёт ошибаться в классификации.

## Лабораторная работа 4: «Реализация глубокого сверточного автоэнкодера для шумоподавления»

**Задачи:**
1. Предобработать обучающие данные;
2. Добавить случайный шум к каждому изображению в массиве;
3. Реализовать архитектуру автоэнкодера;
4. Протестировать подавление шума на изображениях с помощью автоэнкодера.

## Лабораторная работа 5: «Реализация трансферного обучения»

**Задачи:**
1. Загрузить и обработать датасет;
2. Создать нейронную сеть из импортированных слоёв и своих оригинальных слоёв;
3. Обучить и протестировать созданную нейронную сеть.

## Лабораторная работа 6: «Реализация U-Net подобной нейронной сети для сегментации изображений дорожного движения с помощью трансферного обучения»

**Задачи:**
1. Загрузить и обработать датасет;
2. Реализовать U-Net подобную нейронную сеть из импортированных слоёв и своих оригинальных слоёв;
3. Обучить и протестировать созданную нейронную сеть.
